# 🐍 Python 100 Days Challenge

A daily Python practice journal, where I am revisiting the fundamentals, sharpening skills, and building real mini-projects one topic at a time.

> **Why does this exist?**
>
> AI can write code. That's not a reason to stop learning. I strongly believe it's a reason to learn *better*.
> Understanding what we're asking AI to do, reviewing its output critically, and knowing when it's wrong
> are skills that only come from actually programming. This repo is proof that fundamentals still matter,
> and hopefully inspiration for anyone else who wants to stay sharp in the age of generative AI.

## 🚀 How to Run

**Requirements:** Python 3.12+

```bash
# Clone the repo
git clone https://github.com/Tirso0882/python-100-days-challenge.git
cd python-100-days-challenge

# Run any project directly, e.g.:
python day_1/for_loops.py
python day_2/conditionals/rock-paper-scissors-game.py
python day_3/hangman_game/hangman.py
python day_4/functions.py
python day_5/bid_game.py
```

No external dependencies — everything uses the Python standard library.
